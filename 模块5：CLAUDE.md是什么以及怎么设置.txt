模块 5：CLAUDE.md 是什么以及怎么设置
① 为什么需要它（没有它会发生什么？）
举个具体的生活场景：比如你正在做一个连载小说的网站，每次打开黑窗口开始新的对话，你都得不厌其烦地跟 Claude 解释一遍：“嘿，记住哦，这是个小说网站，面向中国读者所以界面要用中文，语言风格要活泼一点，数据库用的是 MySQL……”
如果没有 CLAUDE.md，你就像一个每天都在带新人的苦命老板，每天都要把这些背景情况重新交代一遍。有了它，这些话你只需要写一次！ 以后 Claude 每次都会默默记住，直接进入正题干活。
② 怎么创建它？（两种方法）
🌟 方法一（强烈推荐）：用 /init 命令让 Claude 自动生成 这是最省事的办法，让 AI 帮自己写工作手册：
打开你的终端，进入你的项目文件夹。这里我们需要用到一个叫 cd 的命令（cd 就是 Change Directory 的缩写，意思就是“进入某个文件夹”）。比如你的项目文件夹在桌面上，名叫 novel_site：
如果你用 Mac：输入 cd Desktop/novel_site 然后按回车。
如果你用 Windows：输入 cd Desktop\novel_site 然后按回车。
输入 claude 启动 AI 小助手。
在底部的对话框里，直接输入 /init 并发送。
Claude 会自动像雷达一样扫描你现有的项目文件，帮你总结并生成一份初始的 CLAUDE.md 文件。这个文件会自动出现在你的项目根目录（也就是你项目文件夹的最外层）。
📝 方法二：自己新建 你也可以直接在你的项目文件夹里，用鼠标右键新建一个文本文档，把它重命名为 CLAUDE.md（注意字母要全部大写，扩展名是 .md）。 (💡 提示：这比较适合你刚刚建好一个空文件夹、里面还没有任何代码的“全新项目”，一切从零开始定规矩。)
③ CLAUDE.md 里应该写什么？
不要用英语写得像教科书一样，直接用大白话写就行。这里有一个适合初学者的个人项目模板例子，你可以直接复制到你的 CLAUDE.md 文件里去修改：
# 项目是什么
这是一个面向中文读者的连载小说网站。

# 技术选择
- 前端页面使用简单的 HTML、CSS 和原生 JavaScript
- 数据库使用 MySQL

# 代码风格偏好
- 所有的代码注释必须用简体中文写，要写得让没有任何编程基础的人也能看懂
- 所有的文件名、函数名请用英文命名（比如用 getUser 而不是 quYongHu）
- 页面设计风格要温馨、活泼一点

# 绝对不能动的东西（红线规则）
- 绝对不要修改 `database_config.js` 文件，那是我的数据库核心配置！
- 遇到报错时，不要随便删除文件来解决，必须先向我解释错误原因

# 常用命令
- 运行项目的命令是：`npm start`
- 检查代码错误的命令是：`npm test`
④ 写 CLAUDE.md 最重要的注意事项（避坑指南）
在写这本“工作手册”时，有两个新手最容易踩的坑，一定要避开：
坑一：写得又臭又长。 如果你的手册写得像一本字典，Claude 反而会“看走眼”，导致最关键的规则被淹没在字里行间。建议把内容控制在一屏能看完的范围，绝对不要超过 5000 个字（也就是 5000 个 token）。
坑二：写一堆废话。 Claude 本来就很聪明，它本来就会做的事（比如“请写出高质量、没有 bug 的代码”这种套话）千万不要写进去。只写它不知道、但你需要它必须记住的东西。 记住：精简的 CLAUDE.md 比臃肿的 CLAUDE.md 效果好十倍！
⑤ 进阶小技巧：全局 CLAUDE.md vs 项目 CLAUDE.md
简单来说，工作手册有两个安放位置，作用范围不同：
项目 CLAUDE.md：放在你具体的项目文件夹里（比如 小说网站 文件夹），里面的规矩只对这一个项目生效。
全局 CLAUDE.md：放在你电脑的用户主目录下（对所有项目生效）。具体路径：
Mac 用户的路径是：~/.claude/CLAUDE.md
Windows 用户的路径是：C:\Users\你的用户名\.claude\CLAUDE.md 你可以把自己的通用习惯（比如“永远用中文回复我”、“每次修改前都要给我解释原因”）写在全局文件里，这样不管你以后做小说网站还是做记账工具，它都会默认遵守你的个人偏好。

🎯 随堂小测验（选一选，看看你掌握了吗？）
1. 当你在编写 CLAUDE.md 文件时，哪种做法是最聪明的？ A. 尽可能写得非常长，把所有的代码原理和基础知识都写进去，越长越好。 B. 只写 Claude 不知道的、特定于你这个项目的重要背景和规矩，尽量精简，不要写废话。 C. 在里面反复写上“请每次给我写没有 bug 的完美代码”这种通用要求。
2. 你想让 Claude Code 每次在你的“小说网站”项目里干活时，都知道有个配置文件绝对不能碰，你应该怎么做最省事？ A. 每次开启新对话跟 Claude 聊天前，先在对话框里打字重复提醒它一遍。 B. 把这句要求写在这个项目文件夹的 CLAUDE.md 文件里，它每次上班都会自动看。 C. 每次让Claude开始干活前，先用/clear清空对话记录，重新开始。
