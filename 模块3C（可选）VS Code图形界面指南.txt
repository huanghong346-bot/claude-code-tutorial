这是一个可选模块。如果你在模块3里选择了桌面App或者终端CLI（黑窗口），并且用得挺顺手的，这个模块可以完全跳过。如果你对着黑色终端窗口感到不舒服，或者你平时已经在用 VS Code 写代码，那这个模块非常适合你。VS Code 方式和终端方式能做的事基本一样，只是界面更友好，选你喜欢的就好！

路线B的用户（想用智谱 GLM）：请务必先完成【模块3B】的配置！配置好 GLM 之后再回来使用 VS Code 界面。由于一个小漏洞，这部分用户在登录时可能会遇到卡壳，请务必仔细看下面【第3步】里的专属解决方法。

【第1步 / 共5步 — 进度20%】：下载并安装 VS Code
VS Code 是什么？ 全称是 Visual Studio Code，它是微软出的一款免费代码编辑器（用来专门写代码的软件）。全球有几千万开发者在用它，你可以把它理解成代码界的“Word文档”。
去哪里下载：打开浏览器，访问官网 code.visualstudio.com，点击显眼的大下载按钮，找到适合自己电脑系统的版本下载。
版本要求：Claude Code 要求 VS Code 版本必须是 1.98.0 或更新的版本。（如果你以前安装过，可以点软件菜单栏的“帮助” → “关于”来查看版本，太旧的话请更新一下）。
安装过程：
如果你用Mac：下载后双击解压，把蓝色图标拖进“应用程序（Applications）”文件夹即可。
如果你用Windows：双击下载的安装包，一路点击“下一步”直到完成即可。

--------------------------------------------------------------------------------
【第2步 / 共5步 — 进度40%】：安装 Claude Code 扩展
扩展（Extension）是什么？ 就像给手机装 App，或者给浏览器装拦截广告的插件一样，在 VS Code 里装“扩展”，就是为了让它多出一个新功能。
具体步骤：
打开装好的 VS Code 软件。
在软件最左侧的竖条边栏里，找到一个由四个小积木方块组成的图标（叫“扩展市场”），点击它。 (💡 快捷键：如果你用Mac，按 Cmd+Shift+X；如果你用Windows，按 Ctrl+Shift+X)。
在弹出的搜索框里输入 Claude Code。
在搜索结果中找到由 Anthropic官方发布 的那个，点击“Install（安装）”。 (⚠️ 注意：市场里可能有名字类似的个人作品，千万不要装错，认准官方！)
🎉 怎么看装好了没？ 安装完后，你会在左侧栏（或者右上角）看到一个闪电图标（⚡ Spark 图标），这就是 Claude Code 的专属入口！
重要提醒：这个扩展里面已经捆绑了所需的一切核心工具，你不需要再去单独安装任何终端命令行程序了！

【第3步 / 共5步 — 进度60%】：登录并完成初始设置
点击刚才找到的闪电图标（⚡），它会要求你授权登录。
点击登录按钮，电脑会自动弹出一个浏览器网页。
路线A用户：直接用你注册的 Anthropic 账号登录授权即可。
路线B用户：等一下！请看下方的特别提示👇
🚨 路线B用户特别注意： 这是一个已知的小坑。虽然你已经在模块3B配置好了智谱GLM，但 VS Code 的扩展有时不能可靠地读取第三方 API 的配置，所以你大概率会被一个登录界面死死挡住，根本走不到“自动对接”那一步。不知道该用什么账号登录？别慌，请用以下任意一种方法解决：
方法一（🌟 强烈推荐）： 不要直接双击桌面图标打开 VS Code。请先打开你的终端（黑色命令行窗口），在里面输入 code . （注意 code 和 . 中间有个空格），然后按回车。这样 VS Code 就会“继承”你终端里已经配好的 GLM 身份，自动绕过登录界面！
方法二（如果方法一不行）： 打开 VS Code 的设置界面（Mac用户按 Cmd + ,，Windows用户按 Ctrl + ,），在顶部的搜索框里搜 "Claude Code login"，找到 "Disable Login Prompt"（禁用登录提示）这个选项，把它打上勾。然后直接关掉那个烦人的登录弹窗就行啦！
🚨 找不到闪电图标怎么办？
原因1：你没有打开任何文件！在 VS Code 里，必须打开一个具体的文件（不能只打开一个空文件夹），闪电图标才会显示出来。随便在电脑上新建一个文本文件拖进去打开试试。
原因2：软件卡住了。试试万能的“重新加载”：按下 Ctrl+Shift+P（Mac用 Cmd+Shift+P），在弹出的搜索框输入 Developer: Reload Window（开发者：重新加载窗口），按回车刷新一下，图标一般就出来了。

【第4步 / 共5步 — 进度80%】：认识 VS Code 里的 Claude Code 界面
点开闪电图标，你会看到一个类似聊天软件的侧边栏。我们来认识几个最核心的元素，用大白话解释就是：
💬 对话框（发号施令的地方）：最下面的输入框。你想要它干嘛，就在这里用大白话打字发送。
📍 @ 符号（划重点功能）：当你打字时输入 @，然后跟上文件名（比如 @app.py ），就是告诉 Claude：“嘿，干活前请你先仔细看看这个文件！”这就相当于开会时把资料直接递到员工手里。
📝 Plan Mode（计划模式）：这就像是**“先审计划再动工”**。在这个模式下，当你布置了任务，Claude 不会直接瞎改代码，而是先用文字写一份“施工计划”给你看。你点头确认后它才开始写。强烈推荐小白使用，防止它把文件改乱！
🔍 Diff 查看器（代码对比器）：当 Claude 写好代码后，编辑器里会出现左右两半屏幕。这就像 Word 的修订模式：左边红色的代表被删掉的旧代码，右边绿色的代表它新写上去的代码。
✅ 接受 / ❌ 拒绝（Accept / Reject）：在 Diff 查看器上方，如果你觉得改得好，点“Accept（接受）”；如果觉得一塌糊涂，点“Reject（拒绝）”，文件就会毫发无损地恢复原样。

🚨 常见问题排雷指南
问题1：装了扩展，还是死活找不到闪电图标（⚡）？ 解决： 除了前面提过的必须“打开一个文件”和“Reload Window”之外，还要确认你的 VS Code 版本。点击菜单栏的 帮助(Help) -> 关于(About)，如果低于 1.98.0，请去官网下载最新版。
问题2：它好像和其他 AI 助手（比如 GitHub Copilot 或 Cline）打架了？ 解决： 如果你电脑里装了其他 AI 插件，有时候会出现快捷键冲突。新手建议在左侧扩展市场里，把其他 AI 插件暂时点击“禁用（Disable）”。
问题3：如果你用 Windows，提示“受限模式”或无法修改文件？ 解决： Windows 会为了安全阻止不认识的代码运行。当你用 VS Code 打开一个文件夹时，如果弹出一个框问你“是否信任此工作区中的作者？”，请务必勾选并点击“是，我信任此作者”，否则 Claude 会被束缚住手脚。
