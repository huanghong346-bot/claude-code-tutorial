② 终端是什么、在哪里找到它？
终端（就是电脑里那个黑色或蓝色的命令行窗口，你在电影里常看到黑客在上面敲满屏英文字母的东西），其实一点都不高深。我们平时习惯用鼠标去点文件夹，而“终端”只是换了一种方式——用打字的方式来指挥电脑干活。Claude Code 接下来就会住在这个窗口里。
找它的方法很简单：
如果你用Mac：
在键盘上同时按下 Command + 空格键，呼出电脑的搜索框。
在搜索框里输入“终端”或者“Terminal”。
看到一个黑色的正方形小图标，按下回车键点开它。恭喜，你成功打开了终端！
如果你用Windows：
按下键盘左下角的 Windows徽标键（或者点击屏幕左下角的开始菜单）。
在搜索框里输入“PowerShell”或者“cmd”（命令提示符）。
看到一个蓝色或黑色的图标，点击它或按回车键打开。恭喜，这就是你的终端了！
⚠️ Windows用户注意：如果你看到 PowerShell 窗口里开头显示 PS C:>，那就是 PowerShell；如果只显示 C:>，那是命令提示符（CMD）。后续安装步骤中我们强烈推荐使用 PowerShell。
③ Node.js 是什么、怎么确认有没有装？
Node.js（一个能让代码在你的电脑上直接跑起来的“运行引擎”或“翻译环境”）。 为什么要它呢？因为 Claude Code 的底层有一部分是需要这个“引擎”来驱动的。如果你电脑里没装这个引擎，Claude Code 就转不动。
怎么检查自己有没有装过？ 打开你刚刚找到的终端，在里面输入这行短命令（注意全部是英文字母，中间有个空格）： node -v 然后按下回车键。
如果你看到屏幕上蹦出一串数字，比如 v18.x.x 或者 v20.x.x，说明你已经装好了（我们需要 Node.js 18 或更新的版本）！
如果电脑提示“找不到命令”（command not found），说明你还没装。你需要去 Node.js 官网（nodejs.org）下载，并像安装普通软件一样一直点“下一步”直到安装好它。
⚠️ Mac用户注意：建议去 nodejs.org 官网直接下载安装包，不推荐用 Homebrew 安装，因为权限设置容易出问题，后续可能影响 Claude Code 运行。
⚠️ 特别防坑提醒：网上的很多老教程会教你用 npm（Node.js 自带的一个软件管家）来安装 Claude Code，但这种 npm 安装方式已经被 Anthropic 官方正式弃用（不再推荐使用了）！我们在下一个模块会教你用官方最新、最稳定的原生安装方式。

在进入下一步正式安装前，请对照以下清单，确认你已经准备好了： ☐ 账号已搞定：要么已注册官方账号并完成付费设置（路线A），要么准备好了路线B的智谱账号。 ☐ 找到了“终端”：已经成功在电脑上打开了那个黑/蓝色的输入窗口（Windows 用户记得确认自己打开的是 PowerShell）。 ☐ 检查了“引擎”：在终端里输入 node -v 能看到版本号，确认 Node.js 已经安装好。
