【第1步 / 共5步 — 进度20%】：注册智谱账号
首先，我们需要去智谱的平台注册一个账号。
去哪里注册：请在浏览器中打开 智谱AI开放平台（bigmodel.cn）。
注册流程：点击右上角的“登录/注册”，直接用你的中国大陆手机号接收验证码即可注册。步骤非常简单，和注册普通的国内 App 没有任何区别。
关于免费额度：为了鼓励大家体验，智谱通常会给新注册用户赠送一定的免费额度（Token 体验金）。注册登录后，在网页右上角点击你的头像，进入“控制台”或“财务中心”，就能看到你的账户余额啦！

--------------------------------------------------------------------------------
【第2步 / 共5步 — 进度40%】：获取并保存 API Key（你的专属计费钥匙）
什么是 API Key？ 你可以把 API Key 理解成你的**“专属银行卡号兼身份证”**。当 Claude Code 这双“手脚”呼叫智谱的“大脑”来干活时，它必须出示这串钥匙，智谱才知道“哦，是你在用，我会从你的账户里扣除一点点相应的跑腿费”。
在哪里找到它：登录智谱控制台后，在左侧菜单栏找到 “API Keys”（或者叫“密钥管理”）。点击“添加新的 API Key”按钮，系统会为你生成一串长长的、像乱码一样的英文字符母。
🚨 超级重要提醒：生成这串 Key 后，请点击旁边的“复制”按钮，复制好之后妥善保存，不要泄露给别人（比如存到你的电脑备忘录里）。它就是你的计费凭证，切记千万不要发给别人，以免被盗刷！

【第3步 / 共5步 — 进度60%】：配置 Claude Code 使用 GLM
这是最关键的一步，我们要把刚才拿到的大脑“钥匙”，装进 Claude Code 的口袋里。这需要我们修改一个名为 settings.json（设置文件）的小文件。请根据你的电脑系统选择对应的操作：
🍎 如果你用 Mac 或 Linux（一键脚本配置）：
打开你的终端（Terminal）。
复制下面这整段代码，粘贴到终端里（这是一段官方推荐的一键配置脚本，它会自动帮你把设置写好）。 ⚠️ 注意：粘贴前，请把最后面的 你的智谱API_Key 替换成你刚才在第2步保存的那串真实钥匙！
mkdir -p ~/.claude && cat > ~/.claude/settings.json << 'EOF'
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://open.bigmodel.cn/api/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "你的智谱API_Key",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-4.5-air",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-4.7"
  }
}
EOF
按下回车键。如果没有跳出任何错误提示，就说明配置成功了！
🪟 如果你用 Windows（手动修改配置）：
找到配置文件：在键盘上按下 Win + R 键，输入 %USERPROFILE%\.claude 然后按回车。这会打开一个文件夹。 (如果提示找不到，请打开“我的电脑/此电脑”，进入 C盘 -> 用户(Users) -> 你的用户名 文件夹，在里面新建一个名为 .claude 的文件夹)。
创建/打开文件：在这个文件夹里，看看有没有一个叫 settings.json 的文件。如果没有，右键 -> 新建 -> 文本文档，把它命名为 settings.json（注意把 .txt 后缀删掉）。
填写内容：右键点击这个文件，选择“用记事本打开”。把你里面的内容全部清空，然后复制下面这段代码粘贴进去：
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://open.bigmodel.cn/api/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "你的智谱API_Key",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-4.5-air",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-4.7"
  }
}
替换钥匙：把代码里 你的智谱API_Key 这几个中文字，替换成你在第2步保存的真实字符。 (💡 配置内容说明：ANTHROPIC_AUTH_TOKEN 就是填你的 API Key，而 ANTHROPIC_BASE_URL 是告诉 Claude Code 我们要把问题发送给智谱的专属兼容地址 )。
保存并关闭：按下 Ctrl + S 保存文件，然后关闭记事本。

【第4步 / 共5步 — 进度80%】：验证配置是否成功
设置好了？我们来检查一下大脑到底接通没有！
关掉你之前打开的所有终端窗口，重新打开一个全新的终端（Windows 打开全新的 PowerShell）。
输入命令：claude 并按回车启动它。
(系统可能会问你：Do you want to use this API key? 你输入 Y 或 Yes 按回车确认)。
成功进入提示符（出现 > 符号）后，输入这个命令：/status 并按回车。
🎉 看到什么算成功？ 如果在输出的信息中，你看到了类似下面这两行字，说明大功告成：
Current model: glm-4.7 （当前模型：glm-4.7）
Base URL: https://open.bigmodel.cn/api/anthropic （基准地址是智谱）
🚨 常见小问题排雷：
问题1：为什么启动后，它还是弹出一个网页非要我登录 Claude 账号？ 解答： 你刚才改完配置文件后，必须把终端彻底关掉重新打开！老窗口是不会识别新配置的。
问题2：Windows 启动报错，提示无法读取 JSON 文件怎么办？ 解答： 肯定是标点符号写错了！JSON 格式非常严格，请打开刚才的记事本，检查一下是不是不小心删掉了双引号 " 或者逗号 ,。实在不行，把文件内容删光，重新复制粘贴一遍。
