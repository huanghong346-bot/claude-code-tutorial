第一种：桌面 App（Desktop App）—— 🌟 最推荐给小白
🧑‍🤝‍🧑 适合什么人： 完全不想看到黑乎乎的终端窗口，想要像安装微信一样，用最简单、最直观的图形界面来使用的朋友。
🛠 具体安装步骤：
如果你用 Mac：前往 Claude 官网（claude.ai/download），下载对应 Mac 的版本（注意区分你的电脑是 Intel 芯片还是 Apple 芯片）。下载后双击打开，把黑色的 Claude 图标拖进“应用程序（Applications）”文件夹。
如果你用 Windows：前往 Claude 官网，下载 Windows 安装包（x64 或 ARM64）。下载后双击运行，一直点“下一步”直到安装完成。
🔑 登录账号： 安装好并打开 App 后，它会要求你登录。
路线A的用户：直接用你注册的 Anthropic 官方账号登录。
🚨 路线B的用户：桌面 App 需要 Anthropic 账号登录才能使用，暂时不适合你。请直接看下面第三种（终端CLI）方式安装，终端方式不需要提前登录账号，配置好 GLM 后同样可以正常使用。
✅ 怎么确认安装成功： 登录后，如果你在软件界面上方看到了一个名为 "Code" 的标签页，点击它能进入一个对话框界面，恭喜你，安装成功！
(💡 提示：如果选了这种方式，下面的两种方法就可以直接跳过啦！)

第二种：VS Code 插件 —— 适合想在代码编辑器里用的人
🧑‍🤝‍🧑 适合什么人： 想要在专业的代码编辑器（比如程序员最爱用的 Visual Studio Code，简称 VS Code）里一边看代码一边让 AI 干活的朋友。
🛠 具体安装步骤：
首先，你需要确保电脑上安装了最新版的 VS Code（版本至少需要是 1.98.0）。
打开 VS Code，我们需要打开“扩展（Extensions）”面板：
如果你用 Mac：按下快捷键 Cmd + Shift + X。
如果你用 Windows：按下快捷键 Ctrl + Shift + X。
在弹出的搜索框里输入 Claude Code，找到 Anthropic 官方发布的插件，点击“Install（安装）”。 (注意：这里我们只做基础安装。关于这个插件里面那些酷炫的按键具体怎么用，我们在【可选模块3C】里为你准备了超详细的教程！)
✅ 怎么确认安装成功： 安装完成后，随便打开一个文件。看一眼软件界面的右上角或左侧边栏，如果你能看到一个闪电图标（⚡ Spark icon），点击它会弹出一个侧边栏让你登录，这就说明成功啦！
(💡 提示：如果选了这种方式，下面的第三种方法就可以直接跳过啦！)

第三种：终端 CLI —— 适合想在命令行窗口直接用的人
🧑‍🤝‍🧑 适合什么人： 就喜欢原汁原味的极客感，想在电脑自带的终端（黑色或蓝色代码窗口）里直接敲字母下达指令的朋友。
🛠 具体安装步骤：
如果你用 Mac：
打开你的“终端（Terminal）”。
复制这行命令粘贴进去，然后按回车： curl -fsSL https://claude.ai/install.sh | bash
如果你用 Windows：
务必打开 PowerShell。(怎么确认没开错？看窗口里面每行的开头，如果是 PS C:\> 就是对的；如果只有 C:\> 说明你开成了旧版的 CMD，请关掉重新搜索 PowerShell)。
复制这行命令粘贴进去，然后按回车： irm https://claude.ai/install.ps1 | iex
(⚠️ 再次提醒：网上有些旧教程会教你用 npm install 来安装，请绝对不要用！那种方法已被官方正式弃用了。)
✅ 怎么确认安装成功： 不管你是 Mac 还是 Windows，等待进度条跑完后，在终端里输入 claude --version 并按回车。如果你能看到一串类似 2.x.x 的版本号，说明大功告成！

🚨 最常见的 5 个安装报错与解决方法
万一安装时卡壳了，别怕！对照下面看看是不是碰到了这些常见小坑，或者直接把报错截图发给你刚才准备好的“AI 临时客服”：
1. 报错信息长这样： Node.js version 18 or higher is required...
原因是什么： 电脑里的 Node.js 引擎版本太旧了，带不动 Claude Code。
怎么解决： 去 Node.js 官网（nodejs.org）下载最新的安装包重新安装。(⚠️ Mac 用户特别注意：请务必直接从官网下载安装包，千万不要图省事用 Homebrew 安装，它引起的权限问题会影响 Claude Code 的运行！)
2. 报错信息长这样： Execution of scripts is disabled on this system... 或者提示权限不足
原因是什么： Windows 系统默认处于安全保护状态，禁止 PowerShell 运行外来脚本。
怎么解决（仅限 Windows）： 点击屏幕左下角开始菜单，搜索 PowerShell，右键选择“以管理员身份运行”。输入 Set-ExecutionPolicy RemoteSigned 按回车，然后输入 Y 确认。关掉窗口，重新打开一个普通的 PowerShell 再次运行安装命令即可。
3. 报错信息长这样： fetch error, connection timeout 或者进度条卡住不动
原因是什么： 你的网络连不上海外的下载服务器。
怎么解决： 检查你的网络代理工具（梯子）是否正常开启，并尝试切换一个稳定的节点，然后重新输入安装命令。
4. 报错信息长这样： Please open this URL in your browser to log in...（而且浏览器没有自动弹出来）
原因是什么： 终端想叫浏览器弹出来让你登录，但是没叫动。
怎么解决： 动动手，用鼠标把终端里显示的这串带有网址的链接复制下来，自己打开浏览器，粘贴进去按回车，就能顺利登录了。
5. 报错信息长这样： command not found: claude 或者 无法将 "claude" 项识别为 cmdlet...
原因是什么： 安装虽然成功了，但电脑的系统还没反应过来（环境变量没更新）。
怎么解决： 最简单的方法：把你现在的终端（或 PowerShell）整个关掉，重新打开一个新的窗口，再输入 claude 试试。
