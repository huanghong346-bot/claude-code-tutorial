模块 8：什么是 Skills（技能包），以及怎么用热门 Skills
当你用到这个阶段，Claude Code 已经是个非常能干的"全栈程序员"了。但如果你想让它在某些特定领域变成"顶尖专家"，就需要用到 Skills（技能包）。
打个直觉易懂的比方：你可以把 Claude Code 本身想象成一部出厂设置的智能手机，虽然自带的功能已经很好用，但 Skills 就像是手机 App Store 里的各种"应用插件"。没有下载修图 App 之前，你的手机也能拍照；但装了修图 App 之后，它突然就多了一个专门处理照片的强大本领。 比如，你给它装上"PDF 技能包"，它就瞬间变成了处理 PDF 文件的专家；装上"调试助手技能包"，它遇到 Bug 时的处理方式就会变得像老专家一样系统、严谨。
💡 Skills 和 CLAUDE.md 的区别（一句话说清楚）： CLAUDE.md 是你给它写的项目说明书（每次新对话它都会从头到尾自动读一遍），而 Skills 是按需加载的专业技能（它平时放在口袋里不占脑容量，只有你需要它用这项技能时，它才会激活）。两者完全可以配合使用！

--------------------------------------------------------------------------------
🚨 重要前提说明
官方的 Skills 自动激活功能，目前需要拥有 Claude Pro、Max、Team 或 Enterprise 的官方付费订阅才能使用，免费的基础账号暂时不支持。 使用智谱 GLM 的国内用户注意： 你配置的 GLM "大脑"暂不支持官方的 Skills 自动无缝激活，但千万别灰心！本模块结尾为你准备了专属的"平替指南"，这些强大的功能你绝大部分依然可以完美使用。

🛠 怎么安装一个 Skill（技能包）？
安装技能包非常简单，主要有两种方式：
方式一（🌟 强烈推荐）：通过 plugin 命令安装 在 Claude Code 的输入框里，直接使用自带的插件安装命令。但请注意，如果是第一次安装官方技能包，你需要先添加官方的"应用商店（marketplace）"。
第一步（只需做一次，添加官方仓库）： /plugin marketplace add anthropics/skills
第二步（安装具体技能包）： /plugin install pdf
方式二：手动下载到技能文件夹 如果你在网上看到别人分享的一个很棒的技能包，你可以把它下载到电脑里的 ~/.claude/skills/ 文件夹中。通常我们会使用 git clone 命令。 (💡 小科普：git 是一个程序员最常用的工具，你可以把它简单理解成一个专门用来"从网上下载和管理代码"的下载器)。
具体格式： git clone 技能包的网址 ~/.claude/skills/技能包名字
安装后怎么管理？ 安装完成后，Claude 会在需要时自动检测并使用这些技能。你也可以在对话框输入 /plugins，调出图形化界面来管理（开启、关闭或卸载）你已经安装的技能包。

🏆 社区最受欢迎的 6 大技能包大赏
我们为你挑选了目前最强大、最好用的 6 个技能包，分为三个层级，建议你从基础层开始慢慢体验。

--------------------------------------------------------------------------------
【第一层：基础实用层（官方出品，小白首选）】
这些是 Anthropic 官方制作的基础技能，简单好用，装上就能立刻见效。
1. docx（Word 文档处理）
能干什么： 赋予 Claude 直接创建、读取和编辑 Word（.docx）文档的能力，不仅能写字，还能处理各种字体格式、插入表格、甚至添加批注。
适合谁： 需要经常用 AI 帮你输出正式的总结报告、合同草案、长篇文案的朋友。
使用示例（你可以这样说）：帮我根据我们刚才讨论的内容，生成一份正式的Word文档总结报告，要有标题、章节分隔和一个对比表格。
2. pdf（PDF 处理专家）
能干什么： 能够极其精准地提取 PDF 里的文字和表格内容，还能帮你合并多个 PDF 文件、拆分页面，甚至自动帮你填写 PDF 表单。
适合谁： 经常需要阅读大量 PDF 论文、财报，或者需要批量处理 PDF 文件的用户。
使用示例（你可以这样说）：请读取@合同.pdf这个文件，把里面所有涉及付款时间和违约条款的段落提取出来，用中文列一个清单给我。
3. systematic-debugging（系统化调试助手）
能干什么： 这是最推荐新手安装的技能之一！当程序报错时，新手或 AI 经常会"瞎猜乱改"，把代码越改越乱。有了这个技能，Claude 会被强制使用一种严谨的"破案"流程：先收集证据 → 提出假设 → 验证假设 → 最后才动手修改代码。
适合谁： 所有用户，特别是每次遇到复杂 Bug 就手忙脚乱、不知从何下手的朋友。
使用示例（你可以这样说）：我的网页点击提交按钮后没有任何反应，也没有报错信息，请用系统化的排查流程帮我找出问题。

--------------------------------------------------------------------------------
【第二层：进阶效率层（让 Claude 工作更稳定专业）】
4. Everything Claude Code（简称 ECC）🌟🌟🌟
这是什么（打个比方）： 如果上面介绍的技能包是单个的 App，那 ECC 就是一整个"超级豪华应用套餐"！安装这一个，相当于同时给你装了几十个经过全世界开发者大量测试、最专业的干活工具。
它的分量有多重： 它是目前整个社区最受认可、最火爆的 Claude Code 增强工具，已经在 GitHub 上获得了超过 10 万颗星，而且是诞生于 Anthropic 官方黑客松的冠军项目！
它具体包含什么（挑几个最牛的）：
专业子代理（Agents）： 比如 planner 专门负责帮你做周密的计划，code-reviewer 专门像资深主管一样审查你的代码质量，找漏洞。
技能包（Skills）： 比如 coding-standards 强制规范代码格式，testing 制定专业的测试工作流。
自动化钩子（Hooks）： 比如在会话结束时，自动帮你把重要上下文写成笔记保存下来；在提交代码前，自动检查有没有不小心泄露了密码。
适合谁： 想要把 Claude Code 从一个"聪明的实习生"变成"稳定、专业、严谨的工程团队"，希望它少犯低级错误的用户。
怎么安装：
第一步（添加仓库）：/plugin marketplace add everything-claude-code@everything-claude-code
第二步（执行安装）：/plugin install everything-claude-code@everything-claude-code
⚠️ 注意提醒： ECC 的功能极其庞大，它会让 Claude 在干活前考虑非常多的规矩，从而增加"大脑"的上下文负担。强烈建议你先把前面几个基础 Skills 用熟了之后再安装它，并且不要一开始就把它里面的几十个功能全打开。
5. test-driven-development（测试驱动开发 / TDD）
能干什么： 强制 Claude 采用一种在专业大厂里非常流行的编程习惯——TDD（先写测试，再写代码）。它会先写一段用来验证功能的"检查程序"，确认检查程序报错后，再去写真正的代码，直到检查通过。这样写出来的代码质量极高，Bug 极少。
适合谁： 想要养成顶级编程习惯、做大项目、希望减少后期因为 Bug 导致疯狂返工的用户。
使用示例（你可以这样说）：我需要做一个计算购物车总价的功能，请先帮我写测试用例，等测试确认会失败后，再写实现代码。

【第三层：高阶玩法层（让 Claude 控制你的浏览器）】
6. Playwright MCP（让 Claude 直接操控浏览器）🚀
价值场景（为什么要用它）： 以前你让 Claude 写了一个网页，你需要自己打开浏览器 → 手动点按钮测试 → 发现报错了 → 截图或复制报错信息 → 贴回给 Claude → 等它改完代码 → 你再刷新浏览器验证。有了这个工具，闭环了！ Claude 可以自己打开浏览器、自己点击按钮、自己看浏览器的控制台报错、自己回去改代码、自己再刷新验证。整个测试过程你完全不用参与！
这是什么： 这是由 Playwright 官方出品的 MCP 服务器。(💡 小科普：MCP 可以理解为让 Claude 连接外部软件工具的一座"桥梁")。它通过浏览器自动化协议，让 Claude 获得了直接控制 Chrome 浏览器的超能力。
它能干什么： 自动导航到某个网页、点击页面上的按钮、填写输入框表单、读取网页控制台的报错信息、监控网络请求、全屏截图、甚至测量网页的加载性能。

💡 实战安装经验分享：
根据我们的实际测试，推荐使用以下方法让 Claude Code 直接帮你完成安装：

**方式一：让 Claude Code 直接帮你安装（推荐）**
直接对 Claude Code 说：
```
"请帮我在当前项目目录安装 Playwright MCP，让我能直接控制 Chrome 浏览器进行网页调试"
```

Claude Code 会自动：
1. 检查项目是否有 package.json，没有就创建
2. 安装 @playwright/mcp 和 @playwright/test 包
3. 创建 MCP 配置文件 .clauderc
4. 配置使用系统已安装的 Chrome 浏览器
5. 进行连接测试验证安装是否成功

**方式二：手动命令安装（备选）**
如果你喜欢自己操作，可以按以下步骤：
```bash
# 1. 创建 package.json（如果没有）
echo '{"name":"my-project","version":"1.0.0"}' > package.json

# 2. 安装 Playwright MCP
npm install @playwright/mcp @playwright/test

# 3. Claude Code 会自动检测并配置
```

验证方式：安装完成后，重启 Claude Code，然后对它说：
```
"请打开浏览器访问我的项目页面，帮我测试功能"
```

使用示例（你可以这样说）：
```
请打开浏览器访问 learn.html，点击侧边栏的"模块1"，检查页面是否正常加载，然后截图给我看看效果。
```
```
我的网页点击提交按钮后没有反应，请打开浏览器帮我调试一下，看看控制台有没有报错信息。
```
```
请测试一下平台切换功能，在 Mac 和 Windows 之间切换，确认对应的内容是否正确显示。
```

⚠️ 限制说明： 这个高级功能要求你的电脑本地安装了 Google Chrome 或 Microsoft Edge 浏览器；但不需要下载额外的浏览器，会直接使用你系统里已有的。

💡 小贴士：Playwright MCP 相比其他方案的优点：
- 不需要下载额外浏览器，使用系统 Chrome 即可
- 安装过程简单，Claude Code 可以全自动完成
- 支持有界面模式，调试时可以看到浏览器窗口
- 官方维护，稳定性和兼容性都很好

🇨🇳 【智谱 GLM 用户专属提示框】
选了路线 B（使用智谱 GLM 大模型）的朋友们，不要因为上面提到"官方 Skills 自动激活不支持免费账号"就觉得亏了！我们来盘点一下你们的可用情况：
Skills 自动激活暂不支持：但这完全不影响大局！你依然可以手动去 Github 把别人写好的 Skills 文件夹下载到你的项目里，然后在你的 CLAUDE.md 文件里加一句话（比如：请参考 ./skills/pdf/SKILL.md 里的规则），就能达到几乎一模一样的效果！
ECC 超级套餐：你可以正常安装和使用，它里面的核心思维模式和钩子绝大部分都能在 GLM 模型下正常运转！
Playwright MCP（浏览器控制）：完全可以使用！ 强烈推荐 GLM 用户尝试本模块的第 6 个技能，这是最能让你感受到"AI 全自动接管"震撼效果的功能！
官方的 "Claude in Chrome" 扩展插件：这个确实需要官方账号授权，GLM 暂不支持，但有了上面的 MCP，我们一样能控制浏览器。
总结： 缺的那一点点全自动的小便利，完全不影响核心体验，该有的重磅武器，咱们一样都不差！
