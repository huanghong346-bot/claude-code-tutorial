🛠 第二部分：用熟了再看的进阶命令
当你觉得基础功能已经不够用时，可以试试这些高级指令：
/config：打开设置面板，配置你的个性化偏好（如界面显示风格）。
/mcp：管理外部工具连接，比如让 Claude 能操控你的浏览器、连接数据库等扩展功能。
/doctor：诊断工具，当 Claude Code 连不上网或频繁报错时，用来给它“看病”排查问题。
/bug：如果你发现了软件漏洞，用这个命令直接向官方报告问题。

⚖️ 第四部分：新手最容易搞混的三对命令
别怕记混，我们用大白话对比一下它们的区别：
1. /clear vs /compact （清理白板）
/clear 是彻底擦除整块白板，让 AI 的大脑恢复成一张白纸。什么时候用：完成旧任务，准备开始全新任务时。
/compact 是浓缩白板上的字，剔除废话，只保留核心笔记。什么时候用：同一个长任务做到一半，白板快写满了需要腾出空间时。
2. /btw vs 普通提问 （提问方式）
普通提问 会被写在白板上，成为长久记忆，并持续消耗未来的“流量（Token）”。
/btw 就像弹出一个“阅后即焚”的临时聊天框，问完就关掉，不会留在历史记录里，不污染当前的工作上下文。
3. /status vs /cost （查看信息）
/status 看的是配置信息：你当前连的是什么模型（如 glm-4.7）、服务器地址对不对。
/cost 看的是消费信息：你这个会话消耗了多少使用额度（Tokens）。
